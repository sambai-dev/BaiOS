# Portfolio media

The orbit thumbnails are original vector illustrations in `app/components/ProjectThumbnail.tsx`. Product names and short purpose labels are part of each cover. No images, videos, fonts, or compiled scene code from the supplied Cipher reference are used.

Project-page screenshots show Sam's own software:

- `rookhold-interface.webp`: the repository's v0.6 console demonstration (`sambai-dev/rookhold`, `docs/assets/console-v0.6.png`). This historical image is labeled separately from the current release facts.
- `portly-interface.webp`: the exact terminal example documented in `sambai-dev/portly`'s README, visibly labeled as a README demo. It does not show live host processes.
- `agentscope-interface.webp`: the actual AgentScope v0.2.0 dashboard running its built-in simulated data source. The screenshot identifies the simulated scenario.
- `trekky-interface-light.webp`: the Trekky repository's earlier light-theme sample dashboard. It shows an empty sample board, not a live user's job search.
- `workbench-interface.webp`: the actual BaiOS desktop running locally.

The Railshift and Subsurface posters and short WebM previews are recordings of the original games in this repository. Models and environments are procedural; no third-party game assets were imported. Market Monitor's thumbnail is an illustrative chart without quoted prices; live data is labeled separately inside the app.

Only optimized WebP stills and short, silent previews are served. Original captures and review recordings are kept outside the deployed public directory. Previews load on hover on devices with a fine pointer and stop when the document is hidden; reduced-motion and data-saving preferences disable them.
